# Magma Linux

**Magma Linux** is an independent Linux distribution project by **Magma Studios**, built on Debian and designed around the KDE Plasma desktop environment.

The goal is to create a polished, accessible desktop experience with a distinctive dark-and-orange visual identity, carefully selected software, and a maintainable system configuration.

## Project goals

- Use Debian as the stable foundation.
- Provide KDE Plasma as the primary desktop environment.
- Develop a consistent Magma visual identity, including themes, icons, wallpapers, and branding.
- Curate useful applications and sensible default settings.
- Build reproducible installation images (ISO).
- Test installation, upgrades, hardware support, and everyday desktop workflows in virtual machines before release.

## Planned technology

| Component | Choice |
| --- | --- |
| Base system | Debian |
| Desktop environment | KDE Plasma |
| Package management | APT / DEB |
| Initial architecture | x86_64 |
| Build tooling | Debian Live Build (planned) |
| Testing | VirtualBox |

## Development

The project is currently in its initial development stage. The repository will contain the configuration, branding assets, package selections, and scripts needed to build and test Magma Linux.

No release ISO is available yet.
